Plánek – PWA balíček

Obsah:
- index.html               (tvoje aplikace + PWA tagy + registrace SW)
- manifest.webmanifest     (PWA manifest)
- sw.js                    (offline cache)
- icons/                   (ikony 192/512 + maskable)

Použití na GitHub Pages:
1) Nahraj obsah ZIPu do složky (např. /planek/) v repozitáři.
2) Otevři URL té složky (např. https://<user>.github.io/<repo>/planek/).
3) V prohlížeči: Přidat na plochu / Instalovat aplikaci.

Poznámka:
- Pokud změníš soubory a chceš vynutit update offline cache, změň v sw.js CACHE_VERSION (např. planek-v2).
